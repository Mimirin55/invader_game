# Invader Game 🚀

This is a simple Space Invader-style game made with C++ and SFML.

I followed this great tutorial to build it step by step:  
👉 [Space Invaders from Scratch by Nick Tasios](https://nicktasios.nl/posts/space-invaders-from-scratch-part-1.html)

This was my first time working with C++ for game development,  
and this project helped me understand the basics of game loops,  
collision detection, and rendering with SFML.

I'm currently learning English and programming,  
so this project was also part of my challenge to improve both skills!
